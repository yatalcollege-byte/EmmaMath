# Squishy Math — האפליקציה של אמה 🍡

אפליקציית תרגול לוח כפל בעברית, מותאמת לטלפון, עם אוסף סקווישים ושמירת התקדמות מקומית.

## מה כלול
- לוחות כפל 2–10, 10 שאלות בכל סיבוב.
- ניקוד, אוסף סקווישים וסטטיסטיקה.
- תרגילים שבהם הייתה טעות מקבלים עדיפות בתרגולים הבאים.
- שמירה בדפדפן של המכשיר (localStorage).
- PWA בסיסי: אפשר להוסיף למסך הבית ולשמור קבצים לשימוש חוזר לאחר טעינה ראשונה.

## איך לפרסם בחינם דרך GitHub Pages
1. היכנסו ל-GitHub וצרו repository חדש בשם `squishy-math`.
2. העלו אליו את ארבעת הקבצים שבתיקייה: `index.html`, `manifest.json`, `sw.js`, `icon.svg`.
3. פתחו **Settings → Pages**.
4. תחת **Build and deployment**, בחרו **Deploy from a branch**, בחרו `main` ואת `/ (root)`, ולחצו Save.
5. המתינו עד שהאתר יפורסם. כתובת האתר תהיה בדרך כלל `https://USERNAME.github.io/squishy-math/`.
6. פתחו את הקישור ב-Safari באייפון של אמה, לחצו על כפתור השיתוף ואז **Add to Home Screen / הוספה למסך הבית**. באנדרואיד: בתפריט Chrome בחרו **Install app** או **Add to Home screen**.

## חשוב לדעת על פרטיות ושמירה
- אין צורך בחשבון משתמש בתוך המשחק, ואין בו פרטי זיהוי או שרת.
- הניקוד, התרגילים והאוסף נשמרים מקומית בדפדפן במכשיר שבו משחקים.
- מחיקת נתוני האתר/הדפדפן או שימוש בדפדפן אחר עלולים למחוק או לא להציג את ההתקדמות. אין סנכרון בין מכשירים.
- GitHub Pages מפרסם את קובצי האתר באינטרנט; אין להכניס למאגר מידע פרטי.
- אם תרצו סנכרון בין מכשירים או גיבוי, נצטרך להוסיף בהמשך מנגנון חשבון/גיבוי.

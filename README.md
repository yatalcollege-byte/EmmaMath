# Squishy Math — Emma v5 🍡⚽🚀

גרסה מעודכנת של אפליקציית התרגול, עם בחירת עולם עיצוב, בחירת גיל ומסלול למידה אוטומטי.

## מה חדש ב-v5
- בחירת נושא: סקווישים, כדורגל, דינוזאורים או חלל.
- בחירת קבוצת גיל: 6–7, 8–9, 10–12 או 13+.
- כפתור „המשך במסלול שלי” בוחר את השלב הבא לפי הגיל וההתקדמות, כך שלא חייבים לבחור לוח.
- עדיין קיימת אפשרות רשות לבחור לוח לתרגול ממוקד.
- הגיל משפיע על קושי השאלות: כפל בסיסי, כפל וחילוק, לוחות עד 12 ושאלות כפל/חילוק במספרים גדולים יותר.
- שומרת על מבנה השמירה הקודם כדי לשמר מטבעות, סקווישים והיסטוריית תרגול מקומית ככל האפשר.
- פרסים של 1, 3 או 5 מטבעות ושאלות שנענו לא נכון מקבלות עדיפות בחזרה.

## עדכון אתר GitHub Pages קיים
1. חלצי את קובץ ה-ZIP.
2. העלי את הקבצים שבתוך `squishy_math` לשורש המאגר הקיים, והחליפי את `index.html`, `manifest.json`, `sw.js`, `icon.svg`.
3. בצעי Commit changes. כתובת האתר הקיימת אמורה להישאר ללא שינוי.
4. לאחר פרסום העדכון, סגרי את האפליקציה לגמרי ופתחי אותה מחדש. אם עדיין מופיעה גרסה ישנה, נסי לסגור ולפתוח שוב או לרענן את האתר.

## שמירת התקדמות ופרטיות
- ההתקדמות נשמרת בדפדפן של המכשיר בלבד; אין חשבון משתמש או סנכרון בין מכשירים.
- הגרסה שומרת את מפתח האחסון המקומי הקודם כדי לנסות לשמר נתונים קיימים.
- מחיקת נתוני האתר/הדפדפן עלולה למחוק את ההתקדמות.
- גיל ועיצוב נשמרים גם הם במכשיר.

## הערה לימודית
המסלול האוטומטי מתקדם לשלב הבא אחרי שתי הצלחות עם לפחות 8 תשובות נכונות מתוך 10. אפשר עדיין לבחור לוח באופן ידני, אבל אין צורך בכך.

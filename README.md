# Squishy Math — האפליקציה של אמה 🍡

גרסה משודרגת לתרגול כפל וחילוק בעברית, עם 5 אפשרויות תשובה ופרסים לפי רמת הקושי.

## מה חדש
- בכל סיבוב 10 שאלות המשלבות כפל וחילוק.
- 5 אפשרויות תשובה לכל שאלה.
- פרסים מדורגים לפי קושי: 1, 3 או 5 מטבעות על תשובה נכונה.
- שאלות שנענו לא נכון מקבלות עדיפות בסיבובים הבאים.
- נשמרים המטבעות והאוסף הקיים בדפדפן המקומי.

## עדכון GitHub Pages
העלי את `index.html`, `manifest.json`, `sw.js`, `icon.svg` למאגר הקיים והחליפי את הקבצים הישנים. שמרי אותם בשורש המאגר ו-Commit changes. הקישור הקיים יישאר ללא שינוי.

## שמירת התקדמות
ההתקדמות נשמרת בדפדפן של המכשיר בלבד. מומלץ לא למחוק את נתוני האתר. אם האפליקציה הותקנה למסך הבית ונראית ישנה, סגרי אותה לגמרי ופתחי שוב לאחר כמה דקות.
